While working on Module 4, two small organizational issues cost us time. First, the project path in Visual Studio Code was set incorrectly, which delayed our setup.

Second, we forgot the Node-RED link and had to search for it again. Once we received it form Kelvin Franke, we didn't adjust the link correctly at first, taking up some more time.
Just like with the pod IDs, router IPs, and credentials in Task 1, our main takeaway is to note down key addresses and links right at the start to avoid unnecessary delays.
